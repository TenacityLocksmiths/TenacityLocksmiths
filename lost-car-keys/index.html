What's covered

New key from code

A new key cut to your car's code, even when no key is left.

On-site programming

The transponder, remote or smart key is programmed to your car where it's parked.

Old keys removed

Where the car allows it, the lost keys can be removed from the car's memory so they no longer start it.

No dealer wait

No waiting for a dealership appointment; we come to you. Usually no tow required.

Spare while we're there

Add a spare key at the same visit so it doesn't happen again.

Frequently asked questions

Can you make a car key without the original?

Yes, for most makes and models. We cut a new key to code and program it at the car.

Do I need to take the car to a dealer?

No. We come to the car and do the cutting and programming on site, so there's no dealer wait.

What do I need to have ready?

Proof of ownership or authorisation, the car's make, model and year, and the VIN if you have it.

Can you stop the lost key from starting my car?

On many cars, yes. We can remove lost keys from the car's memory when programming the new one.

What are your hours?

Public hours Monday–Friday 8:00am–5:30pm. Saturday and Sunday are closed. After hours: emergency by arrangement.
